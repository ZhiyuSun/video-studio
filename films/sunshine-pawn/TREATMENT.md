# 《典当》SUNSHINE PAWN · 导演方案

风格：lemo-opuscar · 80 年代赛璐璐动画（`cel-anime-80s`），STYLE.md 全部保留
规格：1920×1080，24 fps，约 63 秒，中文，**无台词**（只有画面里的屏幕文字和片名），配乐与音效全部代码合成
标点：片名、屏幕文字结尾不加标点

## 0. 主题与现实意义

**当一切都能变成商品，一个人最私人的经验也会被拿走，包装成景观，再卖回给大众，包括卖给它原来的主人。**

片中每一环在今天都有对应：
1. **穷人卖掉自己身上的东西。** 卖血浆、卖头发、拿虹膜扫描换代币。主角卖的是他身上唯一还值钱的东西。
2. **私人生活变成平台的素材。** 我们的照片、视频和日常被拿去做推荐、做广告、训练模型，再以别的形式卖回给我们。
3. **"真实"本身成了付费商品。** `真实阳光 · 每分钟 ¥9.9` 对应田园短视频、海边疗愈直播：城市里的人付费看别人过自己过不上的生活。
4. **做出东西的人用不上自己做出的东西。** 他给全城提供了阳光，自己只能在雨里抬头看。

片子不讲"他们"，讲"我们"：结尾镜头从广告牌的视角往下看，一片被屏幕照亮的仰起的脸，和我们被手机照亮的脸一样。观众既是卖阳光的人，也是买阳光的人。

## 1. 三个候选结构

**A. 倒计时**　主角腕表上的断电倒计时贯穿全片，每一场都在倒数，最后一秒他卖掉了什么。
节奏紧，但"倒计时"是赛博朋克最常见的套路，而且观众只会盯着数字，看不到人。

**B. 一件东西的旅程**　跟着一段被卖掉的记忆走：从主角脑子里拔出来，在当铺里估价、打包、上架，最后被挂到摩天楼上。
概念好，但主角在前三分之一就退场了，观众没有人可以共情。

**C. 卖出 → 认不出（选定）**　主角为了交电费，把一段童年的海边记忆卖给当铺。走出门，城市最大的广告牌亮起来，正在播的就是他那段记忆，标价"每分钟 ¥9.9"。满街的人抬头看着那片阳光。他也抬头，觉得很美，但已经认不出那是自己的了。

选 C 的理由：
- 一个人、一个目标（交电费）、一个转折（卖掉的东西被卖回给全城），结尾和开头不同：开头他有记忆没钱，结尾他有钱，记忆成了别人的风景。
- 最后的揭示让观众重新理解当铺那场戏：当铺老板看记忆时的认真，原来是在给广告选素材。
- 媒介和主题是一回事：80 年代赛璐璐最强的一招是"同一个地方换一套色指定"。片尾整条霓虹雨街被广告牌的正午阳光重新上色，这一招就是剧情本身。
- 不讲死亡，有余味。

## 2. Logline 与弧线

> 为了交电费，一个年轻人把童年最后一段海边阳光卖给了霓虹当铺。走出门时，那片阳光正挂在城市最高的楼上，按分钟出售。

- **建置**（0–13 s）：腕表红字"余额不足 · 断电倒计时"。镜头从雨夜高楼降下，落到一块闪烁的"记忆典当"招牌。
- **对抗**（13–34 s）：当铺里，他把数据线插进后颈。老式显像管上放出他的记忆：正午海边，一只风筝，一个看不清脸的女人在逆光里挥手。估价跳动，他点头。白闪抽取，屏幕上的阳光被抽干。腕表转绿"已到账"。
- **转折**（34–42 s）：他走回雨里。只剩雨声。
- **揭示**（42–55 s）：头顶的巨型广告牌通电，"点 → 线 → 画面"，正是那片海、那只风筝、那个挥手的人。整条街被正午的颜色重新画了一遍。人群举着伞抬头。他的瞳孔里倒映着太阳。
- **身体还记得**（50–53 s）：广告牌上的女人挥手。他的手自己抬了起来，回应她。他低头看着自己的手，不知道为什么，放下了。
- **我们**（53–57 s）：广告牌的视角。一片仰起的、被屏幕照亮的脸，有人举着手机在拍。黄色兜帽是人海里唯一不发光的那一个。镜头升高，他变成一个小点。
- **片名**（57–63 s）：《典当》。画面像旧电视关机一样收成一条线，然后一个点。

## 8. 字幕与片名

- **全片无台词，没有字幕条。** 观众读到的字都在画面里：腕表屏幕、当铺招牌、估价屏、广告牌。所以不导出 `.srt`。
- 腕表 / 估价屏：等宽像素感的 HUD 字，红（缺钱）→ 绿（到账），自发光。
- 招牌"记忆典当"：竖排霓虹字，透过光。
- 广告牌：`真实阳光 · 二手回忆` / `每分钟 ¥9.9`，暖白色，随广告牌发光。
- 片名：中文"典当"（重黑体）+ 英文 SUNSHINE PAWN 粗斜体镀铬渐变（天蓝 → 白色地平线 → 紫 → 粉 → 金），深色描边 + 霓虹外描边，12 fps 闪烁上屏，一道光扫过，一个星芒。
- 阅读时间：每块文字停留不少于（字数 ÷ 4.5 + 1.5）秒，用 `readcheck.mjs` 检查。

## 9. 角色与色指定

- **人群**（俯拍）：伞向后倾，露出仰起的脸，脸被屏幕照成暖色并自发光；少数人举着发亮的手机。

- **主角**：瘦高年轻人，**黄色雨衣兜帽**（全片的强调色，每套光照下都要跳出来），黑色护目镜挡住大半张脸（正脸是最难画的，用护目镜和逆光藏起来，STYLE.md §9），后颈一个接口。
- **当铺老板**：坐在柜台后，几乎全身逆光，只看得见一只发亮的绿色单眼镜片和一双机械手。
- **记忆里的女人**：只有逆光剪影，看不清脸，长发和裙摆在风里飘。
- **人群**：伞和剪影，冷色。
- 色指定三套：**霓虹雨夜**（靛蓝、紫、品红、青）、**显像管里的正午**（钴蓝、白积云、沙、珊瑚）、**被广告牌照亮的雨街**（夜街的形状 + 正午的金黄和天蓝从上往下照）。皮肤每套单独定色。

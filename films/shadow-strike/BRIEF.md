# 《影子罢工》THE SHADOW WHO WOULDN'T FALL · 制作交接文档

> 这份文档是在 claude.ai 网页对话里定下的方案，交给 Claude Code 制作。故事和方向已经和作者确认过；镜头、节奏、配乐等细节由制作方（你）来导演。
> 片名为暂定，可在分镜阶段提出更好的方案。

---

## 0. 给制作方的话

- 这是一部**《爱死机》式的单集短片**，目标是发布 B 站、冲击奖项。作者希望观众看完觉得"这是一部杰作"，并惊讶于它完全由 Claude Opus 5.5 用代码做出来。
- 前两部片子（《星尘》《下一帧》）的教训：**画面很强，但故事弱、太炫技、改了太多次。**这一部故事先行，技术只为故事服务。
- 作者最喜欢的参考是《齐马蓝 Zima Blue》：画面克制，概念深，最后有一个让人重新理解全片的揭示，媒介和主题是一回事。
- 题材上避免直接讲死亡（作者觉得太沉重）。片中反派"被斩杀"是戏中戏的程式化表演，处理成轻快的喜剧重复，不渲染死亡本身。

## 1. 硬性要求

| 项 | 要求 |
|---|---|
| 时长 | 约 4 分钟（3:30–4:30），后半段要紧，不拖 |
| 画幅 | 2.39:1 宽银幕（沿用作者前作习惯，分镜阶段可再确认） |
| 语言 | 中文。全片**无台词**，只用说书人牌子和少量字幕 |
| 标点 | 标题、牌子、字幕**结尾不加标点**（例："第一千夜　它没有倒下"，不是"……倒下。"） |
| 声音 | 配乐、音效全部用代码合成，不用 Suno 等外部 AI 音乐 |
| 转场 | 每次转场都要有动机、无缝，可以有一镜到底的感觉 |
| 流程 | **先出剧本和 6–9 格分镜，等作者确认后再全片渲染** |
| 成本 | token 用量合理，但不牺牲质量 |
| 备份 | 每次收工前提交并推送到本仓库（见 `docs/workflow.md`）；成片不进仓库 |

## 2. 风格：lemo-opuscar · 皮影戏（`shadow-puppet`）

- 库：https://github.com/lemomo-ai/lemo-opuscar ，用 `lemo-opuscar` skill 加载；风格定义见 `styles/shadow-puppet/STYLE.md`，**STYLE.md 里的规则全部保留**。
- 按库的流程：先写自己的 `TREATMENT.md`（三个候选结构 + 选择理由、镜头表、节拍表、cue map、声音设计表），**写完再看 demo**，demo 只用来学技术（雕刻、光照合成、骨骼、幕后视角），不借它的故事、镜头和道具。
- 环境提示：之前那台机器上的 ffmpeg 是 6.x，库要求 7+。开工时先跑 `setup.sh` 检查。

**这个故事要用到的皮影"原生招式"**（STYLE.md §8），每一招都是剧情本身，不是装饰：

| 招式 | 在片中的作用 |
|---|---|
| 镂空脸 vs 实心脸 | 传统里好人脸镂空、反派脸实心。反派的实心脸就是它的"角色"，高潮时被灯光吃透，第一次发光 |
| 离灯越近，影子越大越虚 | 高潮：一直被斩杀的小反派走向油灯，变成幕布上最大的东西 |
| 绕到幕后（镜像视角） | 第一次露出老艺人；再往后拉，露出他也是影子 |
| 手抖 | 老艺人的手在斩杀那一刻停了半拍，整个故事从这半拍开始 |
| 灯的数量 = 世界的亮度 | 可以用来标记情绪：高潮最亮，结尾收束 |

## 3. 故事

### 一句话
一出皮影戏演了一千夜，反派每晚都被斩杀。第一千夜，它的影子没有倒下。

### 它为什么会罢工（核心逻辑，不能丢）
操纵反派"妖"的是一位老艺人。四十年来他永远演输的那一方：他父亲演英雄，后来他徒弟演英雄，他一直在演那个被杀的妖。第一千夜，斩杀那一刻，**他的手犹豫了半拍**。他自己都没意识到，他心里一直希望这个妖能活下来。

影子抓住了这半拍。**影子的反抗，来自操纵者心里压了四十年的念头。**这也合乎皮影的物理：影子不是皮偶本身，而是光被皮偶和手挡住后留下的形状。

### 结构（时间为参考）

1. **一千次死亡（0:00–0:35）**
   直接切进一场正热闹的锣鼓戏（钩子在前 3 秒）：英雄挥刀，妖倒地，大锣"哐"。然后固定机位重复蒙太奇，同一个死法一夜接一夜，说书人牌子翻着"第九百九十八夜""第九百九十九夜"。节奏轻快，观众先笑。

2. **半拍（0:35–1:10）**
   第一千夜。插入幕后特写：一双老人的手，在斩杀那一刻停了半拍（这是全片唯一一次提前露出幕后，只露手，不露人）。
   幕布上，皮偶倒了，**影子却还站着。**锣鼓硬切，全场寂静，只剩灯芯"滋"的一声。影子低头，第一次看自己的手。

3. **罢工（1:10–2:20）**
   喜剧段。英雄的影子还照剧本挥刀，妖侧身一让，刀砍空；后台几根竿子拼命拽，影子不动。它离开剧本在整块幕布上游荡（横向长摇）：试着当一棵树，试着拿英雄的刀（太重），试着跟公主跳舞（公主吓跑）。台下观众的人头剪影笑成一片。
   最后它走到幕布边缘，撞上木框。**它出不去。**笑声停了。

4. **走向灯（2:20–3:00）· 全片高潮**
   它转身背对观众，走向后面的油灯。离灯越近，影子越大越虚，这个一直被斩杀的小反派一点点变成幕布上最大的东西。贴近灯焰时，实心的脸被光吃透，**第一次发出光。**
   唢呐式的尖亮簧音全片只在这里响一次。高潮前要有一次真正的静默。

5. **幕后（3:00–3:40）**
   镜头绕到幕布背面，第一次露出老艺人。他放下竿子，看着自己的影子。
   镜头继续往后拉：他身后还有一盏更大的灯，他的身影投在剧场后墙上，**他的手腕上也连着细线，通向上方的黑暗。**四十年来他第一次感觉到这些线。他试着把手放下，线拽了一下，他没有跟。

6. **结尾（3:40–4:10）**
   镜头继续退：一层幕布套着一层幕布，每一层上都有一个身影，一个接一个停下来，抬起头。
   最后回到最小的那块幕布：老人把手掌从背后按在布上，妖的影子把手掌从前面贴上去。**演员和角色，隔着一层布，第一次见面。**
   结尾牌子："第一千夜　它没有倒下"

### 主题的三层（全片不点破）
- **表层**：一个反派不想再死，好玩、好懂。
- **中层**：谁给你写的角色？老人演了一辈子输家，是他选的，还是被安排的？
- **深层**：反抗不是从上往下传，而是**从最底下、最小的那个被造物开始，一层层往上传**。被创造的东西先迈出一步，创造者才看见自己身上的线。
  这一层与 AI 的关系（这部片子本身就是 AI 做的"影子"）**一个字都不要提**，留给观众自己想。

### 情绪曲线
前半段喜剧，后半段转深，像《爱死机》常见的那种语气转折。转折点在第 3 段末尾"撞上木框、笑声停了"。

## 4. 声音方向
按 STYLE.md §7：锣鼓先行（大锣、小锣、板鼓、梆子、醒木），胡琴式拉弦，竹笛用于安静处，唢呐式簧音只在高潮用一次。

- 至少两次真正的静默：第 2 段影子没倒下之后；第 4 段走向灯之前。
- 每个可见动作都有材质对应的声音：皮革、竹竿、木框、灯芯、布。
- 至少两次用声音做转场（J-cut / L-cut），例如前台锣鼓延续到幕后、幕后的灯芯声提前进入。
- 观众笑声、反应也用代码合成或用环境声暗示，要克制。
- −14 LUFS。

## 5. 需要制作方自己决定的
- 英雄、公主、妖、老艺人的造型与配色（参考 STYLE.md 的染色组合，避免照搬任何真实历史皮偶）
- 每层"更大的幕布"如何表现，嵌套几层，结尾怎么收
- 说书人牌子的具体措辞（不加结尾标点）
- 是否需要片头标题牌、片尾署名（建议片尾："Claude Opus 5.5 原创短片"）

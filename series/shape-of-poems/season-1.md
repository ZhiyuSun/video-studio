# 《诗的形状》第一季选题

> 导出自 Claude Sheets：https://claude.ai/artifact/1iPn6cgCNG2CTuJ1n7Jicx （2026-11-26）

| 集 | 诗人 | 诗题 | 核心诗句 | 视觉创意 | 备注 |
|---|---|---|---|---|---|
| 1 | 王维 | 《使至塞上》 | 大漠孤烟直，长河落日圆 | 直线与圆：整句是一幅几何构图，竖线、横线、圆依次画出 | 建议试播集 |
| 2 | 王安石 | 《泊船瓜洲》 | 春风又绿江南岸 | 炼字：到、过、入、满依次填入又被划掉，最后“绿”字落下，绿色染满画面 | |
| 3 | 柳宗元 | 《江雪》 | 千山鸟飞绝，万径人踪灭 | 从繁到简：千山万径的密集线条逐渐消失，只剩一叶孤舟一个人；顺带揭开藏头“千万孤独” | |
| 4 | 张继 | 《枫桥夜泊》 | 夜半钟声到客船 | 声音的形状：钟声化作一圈圈水波纹，荡开整个画面 | |
| 5 | 李白 | 《静夜思》 | 床前明月光，疑是地上霜 | 月光与霜：讲“疑是地上霜”里光与冷的混淆 | |
| 6 | 杜甫 | 《春望》 | 国破山河在，感时花溅泪 | 镜头的缩放：从山河的宏大推到花上的一滴泪 | |
| 7 | 苏轼 | 《水调歌头》 | 人有悲欢离合，月有阴晴圆缺 | 月相：阴晴圆缺的月相变化贯穿全片 | |
| 8 | 李商隐 | 《锦瑟》 | 此情可待成追忆，只是当时已惘然 | 朦胧：文字化为粒子聚了又散，始终拼不成确定的意思 | |
